# Teixonobre Cursos

[Read this README in English](README.en.md)

## Sobre o projeto

O **Teixonobre Cursos** é um projeto de website institucional para uma
escola de idiomas. A proposta é apresentar a instituição e divulgar seus
cursos de Alemão, Inglês, Francês e Espanhol por meio de uma identidade
visual elegante, acolhedora e consistente.

## Cursos oferecidos

-   **Alemão**
-   **Inglês**
-   **Francês**
-   **Espanhol**

As apresentações dos cursos utilizam textos nos respectivos idiomas para
aproximar o visitante da experiência de aprendizagem.

## Identidade visual

A identidade visual combina azul-marinho, dourado, verde e detalhes em
roxo. O símbolo da marca reúne uma coroa, um livro aberto e elementos
botânicos, representando conhecimento, tradição e conexão entre
culturas.

## Estrutura e tecnologias

O projeto foi desenvolvido como uma página web utilizando:

-   **HTML5** para a estrutura do conteúdo;
-   **CSS3** para a apresentação visual e a responsividade.

## Como visualizar

1.  Baixe ou clone este repositório.
2.  Abra a pasta do projeto.
3.  Abra o arquivo `index.html` em um navegador.

Se o projeto estiver organizado de outra forma, ajuste o nome do arquivo
inicial conforme a estrutura do repositório.
