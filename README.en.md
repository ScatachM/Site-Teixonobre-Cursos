# Teixonobre Cursos

[Leia este README em português](README.md)

## About the project

**Teixonobre Cursos** is an institutional website project for a language
school. Its purpose is to introduce the school and showcase its German,
English, French, and Spanish courses through an elegant, welcoming, and
consistent visual identity.

## Courses

-   **German**
-   **English**
-   **French**
-   **Spanish**

The course descriptions use their respective languages to give visitors
a small preview of the learning experience.

## Visual identity

The visual identity combines navy blue, gold, green, and purple accents.
The brand symbol brings together a crown, an open book, and botanical
elements, representing knowledge, tradition, and connection between
cultures.

## Structure and technologies

The project is built as a web page using:

-   **HTML5** for the page structure and content;
-   **CSS3** for styling and responsive presentation.

## How to view the project

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in a web browser.

If the project uses a different entry-point filename, replace
`index.html` with the correct filename.
